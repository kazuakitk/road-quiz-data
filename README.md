# road-quiz-data

道路クイズアプリで使用する、日本の道路データセットです。

このリポジトリは **ODbL 1.0** で提供されます。OpenStreetMap のデータから派生したデータベースであるため、
ODbL 第4.4条にもとづき、加工後のデータをここで公開しています。
公開しているのは**データだけ**で、生成に使ったスクリプトは含みません。

## 収録データ

| ファイル | 内容 | 出典 | サイズ |
|---|---|---|---|
| `national.json` | 国道 **451路線** のジオメトリ、路線名・bbox | OpenStreetMap | 6.3 MB |
| `streets.json` | 通り名つき道路 **5,630件**（ユニーク 4,395名称）、英語名・路線番号 | OpenStreetMap | 2.7 MB |
| `kaido.json` | 江戸期の主要街道 **37本**（五街道＋脇街道）。起点・終点つき | **CODH（CC BY 4.0）** | 0.9 MB |
| `startend.json` | 国道全 **459路線** の起点・終点・重要な経過地 | e-Gov法令検索 | 85 KB |
| `cities.json` | 市区町村 **4,066件** の座標（役場・市街地の位置） | OpenStreetMap | 0.36 MB |
| `shukuba.json` | 江戸期の宿場 **1,520件**（ふりがな・所属街道つき） | **CODH（CC BY 4.0）** | 0.19 MB |
| `expressways.json` | 高速道路・自動車専用道路 **687路線** | OpenStreetMap | 1.7 MB |
| `tollroads.json` | 有料道路（高速道路をのぞく） **91路線** | OpenStreetMap | 0.1 MB |

`kaido.json` は **OpenStreetMap ではなく CODH の『江戸主要街道データセット』**
（CC BY 4.0）から作っている。OSM の「〜街道」を集める方法も試したが、

- 現存する区間しか拾えず、1本の街道が細切れになる（薩摩街道は16片）
- 観光道路が混ざる（メルヘン街道・日本ロマンチック街道・サラダ街道）
- 「東海道」「中山道」は末尾が「道」なので、機械的な抽出から漏れる

という問題があった。CODH のデータは五街道と脇街道が1本ずつ切れ目なく入っており、
起点・終点（「江戸→京都」）も付いている。支路は本路にまとめてある
（分けると「西国街道【支路】」という名前が出題に出てしまう）。
OSM 側の「〜街道」は現代の通り名として `streets.json` に残している。

`expressways.json` は `highway=motorway`、`tollroads.json` は `toll=yes` から
抽出している。日本では `motorway` に無料の自動車専用道路（地域高規格道路）も
含まれるため、`expressways.json` は「高速道路」だけではない。

インターチェンジのランプ（`motorway_link`）は路線ではないので除いてある。
入れると有料道路の6割がランプになり、高速道路とも重複する。

抽出日 2026-08-27。国道は約10m、市街地の通り名は約5mに間引いてあります。

## データ形式

座標は `[経度, 緯度]` の順（GeoJSON と同じ）で、小数第5位（約1m）に丸めてあります。

```jsonc
// national.json — キーは国道番号（文字列）
{
  "1": {
    "no": 1,
    "name": "国道1号",
    "bbox": [135.50058, 34.6701, 139.77454, 35.68537],  // [西, 南, 東, 北]
    "geom_km": 1194.8,   // 収録ジオメトリの総延長。後述の注意を必ず読むこと
    "span_km": 404.5,    // bbox の対角距離。地図上の広がり
    "pts": 3146,         // 頂点数
    "lines": [ [[139.77454,35.68405],[139.76,35.67]], ... ]  // 線列
  }
}
```

### 同名の道路は `part` で分かれている

「中央通り」のような一般的な名前は、同じ県内の別の市にも存在する。
県 × 名前でまとめると別々の道路が1本として扱われ、地図上で線が飛び飛びになる。
そのため**端点どうしが2km以内の線だけを1つの道路**とみなし、離れているものは
別レコード（`part` 違い）に分けてある。

例: 千葉県の「中央通り」は3本 — 成田付近 4.8km / 船橋付近 1.6km / 木更津付近 0.7km。

`pref` + `name` + `part` の3つ揃いで初めて一意になる。**`name` だけを鍵に使わないこと。**
298の名前が複数に分割されている。

### `geom_km` と `span_km` の違い（重要）

**`geom_km` は路線の実延長ではありません。** OpenStreetMap では上下線が別々の way として
登録されるため、単純に合計すると実延長のおおむね2倍前後になります。
バイパスや重複区間も加算されます。

| 路線 | `geom_km` | `span_km` | 実際の感覚 |
|---|---|---|---|
| 国道1号 | 1194.8 | 404.5 | 東京〜大阪 |
| 環七通り | 116.7 | 30.5 | 環状線1周 約53km |
| 言問通り | 6.65 | 4.0 | 約3.5km |

**ユーザーに「路線延長」として表示しないでください。** 誤情報になります。

用途の使い分け:

- **`span_km`** — 出題時のズーム決定、難易度分け、「地図に描いて見えるか」の判定に使う。
  上下線の二重計上を受けないため、この用途ではこちらが正しい指標です。
- **`geom_km`** — 収録データ量の目安。描画負荷の見積もりなど内部処理向け。

```jsonc
// streets.json — 配列
[
  {
    "name": "言問通り",
    "pref": "東京都",
    "en": "Kototoi-dori Avenue",   // 未設定なら null
    "ref": "319",                   // 都道府県道番号。未設定なら null
    "hw": "primary",
    "part": 0,          // 同名の道路が離れて複数ある場合の通し番号（後述）
    "bbox": [...], "geom_km": 6.65, "span_km": 4.0, "pts": 25,
    "lines": [ ... ]
  }
]
```

```jsonc
// startend.json — 配列
[ { "no": 1, "start": "東京都中央区", "end": "大阪市", "via": ["東京都千代田区（霞が関一丁目）", ...] } ]
```

## 生成方法

OpenStreetMap 由来のものは Overpass API から都道府県単位で取得し、
Douglas-Peucker で間引いています（国道 約50m、市街地の通り名 約10m）。
元の精度が必要な場合は OpenStreetMap から直接取得してください。

生成に使ったスクリプトはこのリポジトリには含めていません。ODbL 1.0
第4.4条が公開を求めているのは加工後のデータベースであって、それを作る
コードではないためです。

  doi:10.20676/00000452、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja)
  https://codh.rois.ac.jp/historical-gis/edo-road/
  OpenStreetMap 由来ではないため ODbL の対象外。表示が必須です。
- **宿場（`shukuba.json`）** — 『江戸宿場データセット』（ROIS-DS人文学オープンデータ共同利用センター作成）
  doi:10.20676/00000477、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja)
- **高速道路の路線一覧・路線番号** — ウィキペディア「[日本の高速道路一覧](https://ja.wikipedia.org/wiki/日本の高速道路一覧)」
  「[高速道路ナンバリング](https://ja.wikipedia.org/wiki/高速道路ナンバリング)」（CC BY-SA 4.0）
  OSM の motorway には区間・構造物の名前も入るため、路線かどうかの判定に使っています。
  路線番号も OSM の `ref` より確かです（`ref` は「C4;468」のように並走する国道の番号が混ざり、欠けもある）。
- **道路ジオメトリ・通り名** — © OpenStreetMap contributors、[ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)
  このデータセットは OSM の派生データベースであり、同じく ODbL で提供されます。
- **国道の起点・終点・重要な経過地** — 出典: e-Gov法令検索「一般国道の路線を指定する政令」（昭和四十年政令第五十八号）
  法令であり著作権の対象外です（著作権法第13条）。
  ※ 最終改正が2004年のため、重要な経過地には市町村合併前の市名が含まれます。
  地図に印を打てるのは起点の約9割・終点の約8割・経過地の約5割で、残りは
  「本荘市」「金谷町」のように合併で消えた自治体です。
  ※ `cities.json` の座標は、行政区域の bbox 中心ではなく **役場・市街地を指す
  place ノード**を優先しています（1,603件）。bbox 中心は海に面した市町村で
  海の上に出ることがあり、高知県土佐市で約22km、須崎市で約16kmずれていました。
  ※ 政令本文の「同都」「同県」（前の項目と同じ都道府県の省略）は、
  取り込みのときに都道府県名へ戻してあります。
  括弧の中に複数の地名が並ぶ経過地（「平塚市（浅間町、袖ケ浜）」）も
  ここでつなぎ直しています。

## 既知の制約

- OpenStreetMap にジオメトリが未整備の国道が8路線あります（394・395・402・416・460・463・476・478号）。
  これらも `startend.json` には収録されています。
- 全国地図では点にしかならない短い国道が13路線あります。最短は国道174号の約310m（`span_km` 0.2）です。
  `span_km` で足切りすると、10km以上が436路線、1km以上が445路線です。
- **通り名の分布は地域差が極端です。** これはデータの欠損ではなく、道路の呼び方の地域差です。

  | 都道府県 | 収録件数 | span 1km以上 |
  |---|---|---|
  | 東京都 | 1,030 | 506 |
  | 北海道 | 817 | 507 |
  | 埼玉県 | 417 | 268 |
  | …（中略） | | |
  | 島根県 | 6 | 1 |
  | 徳島県 | 1 | 0 |
  | 高知県 | **0** | 0 |

  高知県は主要道路 3,000本・260名称を調べても「通り」「街道」で終わる名前が1件もありません。
  当地では「○○線」（県道名）や「○○バイパス」が使われるためです。
  **都道府県単位で通り名を扱う設計にすると、20県が実質空になります。** 地方ブロック単位を推奨します。
  国道（`national.json`）は全国で均質なので、この制約を受けません。
